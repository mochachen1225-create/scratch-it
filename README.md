# 抓爛它！ Scratch It!

療癒解壓的手機網頁小遊戲。手指一滑，貓爪在紙上抓出四道痕、紙屑飛起來、沙沙響；抓爛了，那張爛紙就是你的作品。三隻貓抓法不同，抓完會產生一張「爪痕畫」圖卡，可以存圖分享。

A relaxing phone-browser toy: swipe to scratch with a cat paw, watch the scraps fly, and keep the mess as a painting. Chinese and English.

👉 https://mochachen1225-create.github.io/scratch-it/

- 三隻貓：總編（效率派）、架構師（優雅派）、小弟（亂抓派）
- 材質：瓦楞紙貓抓板、沙發；之後解鎖紙箱城堡、長毛地毯、窗簾、衛生紙捲、聖誕禮物紙箱
- 不比分數、沒有倒數；不連網、不收集資料（進度和收藏冊只存在自己手機）
- 聲音全部用 Web Audio 現場合成；目前所有圖都是程式畫的
